# The Wedding Home

Layered Indian wedding OS. The Wedding Home is where the family runs the wedding and where guests visit. Resume first, take time.

## Rules that do not bend

- Many Admins and Managers. Organisers: bride, groom, parents, siblings, close family, trusted friends.
- **Same data for all organisers.** No private expenses, tasks, or departments.
- **Only Admin** invites, removes, or changes member roles.
- Guests never sign up. They open the invitation link.

## Guests may

Open invite · events they are invited to · RSVP · attending **counts** (not names) · wedding info · venue map (tap → Google Maps) · shared gallery (see and upload photos/videos) · Live URL

## Organisers

Family app: Dashboard, Events (venue map → Google Maps), Guests (WhatsApp + email invite), Tasks, Expenses (spend log), Vendors (My vendors + nearby, no booking), Website (Admin), Preview as guest, Photos, Details, Members (Admin), Account.

## Build order

1. Auth, wedding, members, events (map → Google Maps)  
2. Guests, invite, RSVP, Share on WhatsApp  
3. Reminders  
4. Tasks, expenses  
5. Theme studio + website + live  
6. Nearby vendor map  
7. Shared photo/video gallery
